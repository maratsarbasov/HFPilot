Connect an assistant

Let ChatGPT or another MCP-compatible assistant use HFPilot to prepare instructions, place calls you request, and read the results. HFPilot must be running on this Mac. It can stay paused while you set up a connection.

OpenAI Tunnel

A private connection for supported OpenAI products. HFPilot includes its launcher; tunnel-client is installed separately. HFPilot itself does not need an installed Python or Homebrew.

  1. Install the official client in Terminal: brew install openai/tools/tunnel-client. If needed, install Homebrew first. This is the supported macOS installation method. HFPilot automatically finds the client in the standard Homebrew locations; no file selection or app restart is needed. You can verify the installation with tunnel-client --version. Use Choose File… only for an existing installation in a custom location. Installing the client does not start the tunnel.
  2. Open OpenAI Platform → Tunnels. Create or select a tunnel and link the Platform organization and ChatGPT workspace that will use it. Creating a tunnel needs Tunnels Read + Manage; using it needs Read + Use.
  3. HFPilot uses the OpenAI API key already saved in Settings. In API key settings, give that key Tunnels Read + Use access while keeping its model permissions. The key and its owner need access to your tunnel. An admin key is not needed to run it.
  4. In HFPilot’s Assistant connections, choose OpenAI Tunnel, paste the complete Tunnel ID, and click Connect. HFPilot starts the installed client in the background, using your saved key and local access code. You can close Settings; no Terminal window is needed.
  5. In ChatGPT Plugins, add a custom MCP server. Choose Connection: Tunnel, select the same tunnel and choose No authentication. Create and install the plugin.
  6. Ask ChatGPT to “Get HFPilot’s status without making a call.” A successful reply verifies the connection. A running local server or successful configuration check alone does not prove that ChatGPT is connected.

People allowed to use this connection share your HFPilot permissions. Restrict it to the intended account or workspace. HFPilot still requires its local access code; “No authentication” skips a separate per-user OAuth sign-in in ChatGPT.

After Connect, the tunnel reconnects when you next open HFPilot. Disconnect stops it and turns off that behavior. Pausing the assistant keeps the tunnel available. Quit HFPilot stops the tunnel; closing a settings window does not. Changing the saved API key reconnects an active tunnel. HFPilot does not launch at macOS login and does not manage tunnels started separately.

Connected means the client successfully contacted OpenAI; verify the full connection with the status request from ChatGPT. If a tunnel is missing there, check its workspace association and permissions. For API clients, use tunnel_id rather than server_url. See the OpenAI guide.

Public HTTPS connections

Tailscale Funnel provides a stable address without your own domain. Quick Tunnel provides a temporary Cloudflare address that changes when restarted. Cloudflare Tunnel uses your own hostname.

Install and run the selected provider using its official instructions. Forward it to http://127.0.0.1:8765, then add /mcp to its public HTTPS address in your assistant. Confirm that address in HFPilot. The assistant can then sign in with OAuth; use Copy Access Code on HFPilot’s approval page. Never enter the OpenAI API key there.

Local clients and results

For clients on this Mac, use the On this Mac section at the top of Assistant connections to copy the MCP URL and access code. The code is used as a Bearer authorization header.

Calls return a job ID immediately. The assistant reads results with get_call. Signed HTTPS event callbacks are optional and need separate support in the assistant; a tunnel does not add that support automatically.

Your files

Settings, credentials, phone pairing and conversations are stored in your user account’s Library/Application Support/HFPilot folder, separately from the application. Updating or moving HFPilot does not replace them. The app bundle contains no account keys, phone bonds or recordings.
